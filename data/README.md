# Ruokalistadata ei kuulu projektin lisenssin piiriin

Tämän kansion tiedostot (`*.json`) kootaan automaattisesti ravintoloiden omilta sivuilta ja
lounaslistapalveluista (mm. lounaat.info, Compass Group, Sodexo). Ruokalistat, hinnat ja muut
tiedot kuuluvat ravintoloille ja kyseisille palveluille.

Projektin MIT-lisenssi ja CC BY 4.0 -lisenssi **eivät koske** tätä dataa. Tiedostoja ei saa
käyttää uudelleen tämän projektin lisenssien nojalla. Jokaisen ravintolan lähde näkyy
datatiedoston `source`-kentässä ja sivun alareunassa.

Tarkista erityisruokavaliot ja allergeenit aina ravintolasta.
